EAPI Web (29)
 Método    Caminho                                            Funcionalidade
 GET       /health                                            Estado da API
 POST      /users                                             Registar conta
 POST      /auth/tokens                                       Iniciar sessão (emite o JWT)
 GET       /users/me                                          Ver a minha conta

                                                              palavra-passe, exige a palavra-passe atual)

                                                              insuranceValidUntil e inspectionValidUntil. Cria o plano de peças
                                                              por defeito (um intervalo por peça, consoante seja carro ou moto)
                                                              e os prazos pendentes indicados
 GET       /vehicles/{vehicleId}                              Ver veículo (firstRegistration, nextService, openAlerts)
 PATCH     /vehicles/{vehicleId}                              Editar dados descritivos do veículo (sem km nem prazos)
 DELETE    /vehicles/{vehicleId}                              Remover veículo (apaga também os dados associados)
 GET       /vehicles/{vehicleId}/deadlines                    Listar prazos legais (IUC, seguro e inspeção)
 POST      /vehicles/{vehicleId}/deadlines                    Criar o prazo pendente de um tipo (IUC, seguro ou inspeção), a
                                                              partir do formulário «Adicionar veículo»
 PUT       /vehicles/{vehicleId}/obd-device                   Emparelhar (ou substituir) o dispositivo OBD do veículo
 GET       /vehicles/{vehicleId}/obd-device                   Ver o dispositivo OBD emparelhado
 DELETE    /vehicles/{vehicleId}/obd-device                   Desemparelhar o dispositivo OBD

                                                              oilTemp e gps, todos anuláveis; um parâmetro conta como
                                                              suportado se vier preenchido
 GET       /vehicles/{vehicleId}/maintenances                 Histórico de manutenções
 POST      /vehicles/{vehicleId}/maintenances                 Registar manutenção (atualiza as peças e fecha os alertas
                                                              dessas peças)
 GET       /vehicles/{vehicleId}/maintenances/{maintenanc     Ver manutenção
           eId}
 PATCH     /vehicles/{vehicleId}/maintenances/{maintenanc     Corrigir custo e notas da manutenção
           eId}
 GET       /vehicles/{vehicleId}/inspections                  Listar inspeções periódicas
 POST      /vehicles/{vehicleId}/inspections                  Registar inspeção periódica (date, result, amount, deficiencies[]);
                                                              se aprovada, fecha o alerta anterior e cria o prazo seguinte; se
                                                              reprovada, o prazo continua pendente
 GET       /vehicles/{vehicleId}/inspections/{inspectionId}   Ver os detalhes de uma inspeção (resultado, validade, valor pago
                                                              e deficiências)
 GET       /vehicles/{vehicleId}/expenses                     Despesas totais do veículo, sem filtros no servidor; cada item traz
                                                              id, category (MANUTENCAO, INSPECAO, IUC, SEGURO), date,
                                                              amount, description e km (só em manutenção)
 POST      /vehicles/{vehicleId}/expenses                     Pagar IUC ou seguro (category, date, amount, description,
                                                              validUntil): paga o prazo pendente desse tipo (ou cria-o primeiro),
                                                              cria o seguinte (com data validUntil) e fecha o alerta
 GET       /vehicles/{vehicleId}/parts                        Listar peças do veículo com o intervalo de manutenção, o próximo
                                                              valor, quanto falta e a origem do intervalo
